01 A Natureza do Projeto

Este sistema é um MVP Funcional (Mínimo Produto Viável) desenvolvido para validar a lógica de cálculo tridimensional que servirá de base para a pesquisa principal da aluna Eduarda Pereira de Lima.

O foco central da pesquisa é o desenvolvimento de um sistema de Inteligência Artificial Aplicada capaz de estimar calorias através da visão computacional. O desafio técnico reside na transformação de uma imagem bidimensional (fotografia) em uma estimativa de volume volumétrico preciso.

Da Engenharia para a Nutrição

A mesma matemática utilizada para calcular o concreto necessário para uma laje é aplicada para estimar a massa de um alimento. Mudam-se as densidades e as escalas, mas a lógica de determinação geométrica via visão de máquina permanece a mesma.

Orientação Acadêmica

Sob a mentoria do Prof. Djones Braz de Araujo Costa na FAETEC-RJ, este projeto busca democratizar o acesso a ferramentas de cálculo e mostrar como a IA pode resolver problemas cotidianos de saúde e infraestrutura.
